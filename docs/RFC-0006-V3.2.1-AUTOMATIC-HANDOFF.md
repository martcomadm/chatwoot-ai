# RFC-0006 — MARTCOM AI V3.2.1 Automatic Handoff Router

## Objetivo
Después de generar el resumen privado de AXEL IA, asignar automáticamente la conversación a un asesor humano real de Chatwoot según el turno del día.

## Regla principal
La rotación de presentación (`AI_INTRO_AGENTS`) y la rotación de handoff son sistemas independientes.

## Secuencia
1. Termina diagnóstico.
2. Aplica `validacion`.
3. Envía mensaje orgánico de transición.
4. Genera `AXEL IA - RESUMEN` como nota privada.
5. Selecciona grupo de turno usando `America/Mexico_City`.
6. Selecciona siguiente asesor persistente.
7. POST a `/api/v1/accounts/:account_id/conversations/:conversation_id/assignments` con `assignee_id`.
8. Solo si Chatwoot confirma éxito, avanza la rotación.
9. Guarda el handoff en memoria y Inspector.

## Persistencia
`/app/data/handoff-rotation.json`

## Fallos
Si Chatwoot responde error:
- no avanzar contador;
- guardar `handoff.status=pending`;
- registrar `handoff_assignment_failed`;
- mantener conversación con AXEL IA;
- reintentar ante el siguiente evento entrante mientras siga asignada a AXEL IA.

## Observabilidad
Eventos:
- `handoff_summary_created`
- `handoff_assignment_started`
- `handoff_assignment_completed`
- `handoff_assignment_failed`
- `handoff_assignment_skipped`

## Rollback
Volver a V3.2.0. El archivo `handoff-rotation.json` puede conservarse: V3.2.0 lo ignorará.
