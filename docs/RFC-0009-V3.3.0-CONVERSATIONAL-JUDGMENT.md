# RFC-0009 — MARTCOM AI V3.3.0 Conversational Judgment Engine

## Objetivo
Evitar que el cuestionario tenga prioridad sobre lo que el cliente realmente está diciendo.

## Jerarquía obligatoria
1. Preferencia o solicitud de atención humana → handoff.
2. Pregunta explícita → responder primero.
3. Objeción → resolver o escalar.
4. Corrección → actualizar memoria.
5. Facts nuevos → extraer todos.
6. Solo entonces → siguiente slot.

## Componentes
- Conversational Judgment Engine.
- Price/Trust Objection Router.
- Slot Governance: available / unavailable / refused / ask_later.
- Subject Resolver V2.
- Name protection para frases de cortesía.
- Inspector 1.3 con estado de Judgment.

## Casos de regresión
- “Mil gracias” no es nombre.
- Segunda insistencia de precio escala a humano.
- “No me gusta hablar con un chat” escala inmediatamente.
- “Ahora no tengo la CURP a la mano” bloquea nuevas solicitudes de CURP.
- “Cotización de qué?” se responde antes de pedir otro dato.
- “Esposo” puede corregir el sujeto del caso.

## Compatibilidad
Los nuevos campos son opcionales y compatibles con memorias V3.2.x.
No se modifica `/app/data` de forma destructiva.
