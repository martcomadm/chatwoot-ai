- Nueva intención COTIZACION_SEMANAS.
- Flujo mínimo: IMSS → edad → nombre → resto.
- Respuestas como “tengo seguro” resuelven IMSS.
- Name Guard bloquea frases de costo/precio.
- Interrupt Layer explícita.
- Precio 3-strikes: 1ª/2ª responder y continuar; 3ª escalar.
