# RFC-0005 — MARTCOM AI V3.2.0 Conversation Orchestrator

Objetivo: priorizar lo que el cliente acaba de preguntar y mejorar la resolución de hechos antes de continuar con el planner.

## Capacidades
- Direct Answer First para precio, servicios y confianza/ubicación.
- Intent B2B/proveedor con handoff y etiqueta `proveedor`.
- `unavailable slots` para CURP/NSS.
- Age Extractor V2: distingue edad de fechas.
- CURP Normalizer V2: acepta espacios y separadores.
- Subject Resolver inicial: padre, madre, esposa, esposo, hijo/a, hermano/a.
- Multi-Fact Extractor para edad, semanas, Ley 73/97 y años sin cotizar.
- Eventos `direct_request_detected` y `fact_extracted` visibles en Inspector.

## Regla principal
Una pregunta explícita del cliente tiene prioridad conversacional sobre el cuestionario, salvo handoff obligatorio o seguridad.
