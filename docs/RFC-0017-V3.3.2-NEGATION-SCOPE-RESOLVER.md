# RFC-0017 — MARTCOM AI V3.3.2 Negation Scope Resolver

## Objetivo
Evitar falsos rechazos causados por mensajes sin puntuación.

## Ejemplo crítico
`No quiero información por favor gracias`

Se trata como `ambiguous`, no como rechazo.

## Reglas
- positive
- negative
- ambiguous
- neutral
- `ambiguous` nunca aplica `no_quiere_el_servicio`
- `ambiguous` genera una sola pregunta de confirmación
- negativas claras conservan el comportamiento actual

Inspector V1.5.2 sin cambios.
